# 🚀 DevSecOps CI/CD Pipeline – Secure Deployment with GitHub Actions & Docker

## 📌 Description

Ce projet met en place un **pipeline CI/CD sécurisé (DevSecOps)** permettant d’automatiser le cycle de vie d’une application, de l’intégration continue jusqu’au déploiement, tout en intégrant des **contrôles de sécurité à chaque étape**.

L’objectif est de garantir la qualité, la sécurité et la fiabilité du code avant toute mise en production.

---

## 🎯 Objectifs

- Automatiser le build, les tests et le déploiement  
- Intégrer des analyses de sécurité (shift-left security)  
- Détecter les vulnérabilités le plus tôt possible  
- Garantir un pipeline reproductible et fiable  
- Appliquer les bonnes pratiques DevOps et DevSecOps  

---

## 🛠️ Stack technique

- **CI/CD** : GitHub Actions  
- **Conteneurisation** : Docker  
- **Backend** : Java / Spring Boot  
- **Sécurité** :
  - Analyse statique (SAST)
  - Scan des dépendances
  - Détection de secrets  
- **Versioning** : Git / GitHub  

---

## 🔁 Pipeline CI/CD

Le pipeline est structuré en plusieurs étapes :

### 1. 🔨 Build
- Compilation de l’application  
- Vérification des dépendances  

### 2. ✅ Tests
- Exécution des tests unitaires et d’intégration  
- Validation de la qualité du code  

### 3. 🔐 Sécurité (DevSecOps)
- Analyse statique du code (SAST)  
- Scan des dépendances pour détecter les vulnérabilités  
- Détection de secrets exposés  

### 4. 🐳 Conteneurisation
- Build de l’image Docker  
- Préparation au déploiement  

### 5. 🚀 Déploiement
- Déploiement automatisé  

---

## 🔐 Approche DevSecOps

Ce pipeline intègre la sécurité dès les premières étapes :

- ✔️ Détection précoce des vulnérabilités  
- ✔️ Validation automatique avant déploiement  
- ✔️ Réduction des risques en production  
- ✔️ Automatisation des contrôles de sécurité  

---

## 📊 Résultats

- Pipeline CI/CD automatisé de bout en bout

- Amélioration de la qualité du code
